# 👁️ DrishtiNet AI — Multilingual Legal Document OCR & Entity Extraction

DrishtiNet AI is an intelligent OCR and Named Entity Recognition (NER) platform supporting Devanagari Hindi (`lang='hi'`) and English (`lang='en'`) document extraction and token classification powered by fine-tuned **mBERT** & **MuRIL** models.
